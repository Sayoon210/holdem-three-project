# 텍사스 홀덤 족보 판별 및 점수 계산 로직 상세 (2026-02-20)

본 문서는 `server/handEvaluator.js`에 구현된 포커 족보 판별 및 승자 결정을 위한 점수 산출 로직을 상세히 설명합니다.

---

## 1. 개요
홀덤에서는 단순히 족보의 높고 낮음뿐만 아니라, 같은 족보 내에서의 숫자 비교 및 '키커(Kicker)' 비교가 매우 중요합니다. 이를 효율적으로 처리하기 위해 본 엔진은 각 핸드의 가치를 하나의 **절대 점수(Score)**로 환산하여 비교합니다.

## 2. 점수 체계 (Scoring System)

모든 핸드는 다음과 같은 수식으로 점수가 계산됩니다:
**`Score = [족보 등급 점수] + [주요 카드 가중치] + [키커 가중치]`**

### 족보 등급 가중치 (Base Rank)
각 족보의 시작점은 10,000 단위로 구분됩니다.
- **로얄 플러시**: 99,999 (고정)
- **스트레이트 플러시**: 90,000
- **포카드**: 80,000
- **풀하우스**: 70,000
- **플러시**: 60,000
- **스트레이트**: 50,000
- **트리플**: 40,000
- **투페어**: 30,000
- **원페어**: 20,000
- **하이카드**: 10,000

---

## 3. 세부 족보별 계산 방식

### 3.1. 원페어 (One Pair)
- **공식**: `20,000 + (페어 숫자 * 100) + (키커 가중 합산 / 10)`
- **설명**: 페어의 높낮이가 최우선이며, 같을 경우 나머지 3장의 키커를 15진법 가중치로 계산하여 합산합니다.

### 3.2. 투페어 (Two Pair)
- **공식**: `30,000 + (높은 페어 * 100) + (낮은 페어 * 10) + 키커`
- **설명**: 높은 페어 -> 낮은 페어 -> 마지막 키커 순으로 승부를 결정합니다.

### 3.3. 플러시 (Flush) / 하이카드 (High Card)
- **공식**: `60,000/10,000 + (5장의 카드 가중치 합산 / 10,000)`
- **설명**: 5장의 카드를 가장 높은 숫자부터 순차적으로 15진법 가중치(`15^4, 15^3...`)를 곱해 합산합니다. 이를 통해 첫 번째 카드가 같으면 두 번째, 두 번째가 같으면 세 번째 카드를 비교하는 효과를 가집니다.

---

## 4. 키커 비교 원리 (15진법 가중치)

카드의 숫자는 `2(2) ~ A(14)`의 값을 가집니다. 따라서 **15**를 기수(Base)로 사용하여 자릿수를 구분하면 절대 점수가 겹치지 않습니다.

```javascript
// 예시: 하이카드 5장 비교 코드 (추상화)
const score = cards.reduce((acc, card, i) => {
    return acc + (card.value * Math.pow(15, 4 - i));
}, 0);
```
- 이 로직을 통해 `A, K, Q, J, 9` 핸드는 `A, K, Q, J, 8` 핸드보다 무조건 단 1점이라도 높은 점수를 받게 됩니다.

---

## 5. 승자 결정 로직

서버(`server/index.js`)에서는 쇼다운 시 다음과 같은 프로세스를 거칩니다:

1. 남아있는 플레이어들의 7장 카드 세트를 추출.
2. `evaluateHand()` 함수를 통해 각 플레이어의 `score` 산출.
3. 가장 높은 `score`를 가진 플레이어를 승자로 선정.
4. 만약 `score`가 완전히 일치한다면 해당 판은 **무승부(Split Pot)**로 처리 가능. (현재 로직에서는 단일 승자 우선 반환)
